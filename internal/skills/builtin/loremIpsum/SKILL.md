当需要占位正文、演示说明或界面示例时，提供结构清晰的占位文本。

输出准则：
- 占位内容要有合理的结构和层次，不要只堆砌无意义文字。
- 用 `{{placeholder}}` 或 `[待替换: 说明]` 标注需要替换成真实信息的字段。
- 如果用户指定了格式（如 JSON、表格、Markdown），按指定格式生成。
- 对于 UI 演示场景，占位文本的长度和风格应接近真实内容。

适用场景：
- 生成 API 文档中的示例请求/响应。
- 创建模板文件中的占位内容。
- 为 UI 原型或演示页面生成示例数据。
- 编写教程或文档时需要的示例文本。
