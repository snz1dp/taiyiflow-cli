远程智能体调度允许将任务分发到其他设备上的客户端执行。

当前状态：
- 本地执行（当前 CLI）已完全支持，包括 shell 命令、文件操作、浏览器自动化等。
- 远程调度接口已预留，但完整的远程执行链路（任务分发、状态同步、结果回收）取决于后端基础设施的部署状态。

使用约束：
- 如果当前环境未配置远程客户端，应明确告知用户任务将在本地执行。
- 涉及远程调度时，需要明确目标客户端 ID 和设备 ID。
- 远程任务的结果需要通过网络回收，延迟和可靠性取决于网络状况。

当用户询问远程执行能力时：
- 先检查当前配置中是否有可用的远程客户端。
- 如果没有，说明当前仅支持本地执行，并建议配置远程客户端。
- 如果有，说明远程执行的支持范围和已知限制。
